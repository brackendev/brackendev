## Open Source

### Agent Skills for AI Coding Assistants

These packages give AI coding assistants language- and framework-specific guidance. They follow the [Agent Skills](https://agentskills.io) open standard and install through [APM](https://github.com/microsoft/apm) into Claude Code, Codex, Cursor, Copilot, Gemini, and other supported tools.

| Package | Scope |
|---------|-------|
| [clojure-skills](https://github.com/brackendev/clojure-skills) | Shared Clojure guidance for `.clj`, `.cljs`, `.cljc`, and `.cljd` files. The other Clojure packages build on it. |
| [clojure-jvm-skills](https://github.com/brackendev/clojure-jvm-skills) | Clojure on the JVM, including Java interop, software transactional memory, and the Clojure CLI workflow |
| [clojurescript-skills](https://github.com/brackendev/clojurescript-skills) | ClojureScript, including JavaScript interop, externs inference, and macro stage separation |
| [clojuredart-skills](https://github.com/brackendev/clojuredart-skills) | ClojureDart on Flutter, including Dart interop, type hints, and `cljd.flutter` directives |
| [fulcro-skills](https://github.com/brackendev/fulcro-skills) | The Fulcro full-stack framework and its Pathom 3 server |
| [biff-skills](https://github.com/brackendev/biff-skills) | The Biff web framework, including project scaffolding, conventions, and deployment |
| [code-lenses](https://github.com/brackendev/code-lenses) | Software design principles for code review and implementation, including grug brain, Tidy First?, and Parse Don't Validate |
